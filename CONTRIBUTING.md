# Contributing

## Commit policy

Do not add AI attribution of any kind to commits, pull requests, or any other
content in this repository. This includes, but is not limited to:

- `Co-Authored-By: Claude ...` (or any other AI tool/model) trailers in commit messages
- The Claude/Anthropic logo or any AI-tool logo in commit messages, PR descriptions, or docs
- "Generated with Claude Code" or similar footers in commits or PRs

All commits and PRs should be authored and attributed to the actual human contributor only.

## Commit granularity

- Commit each feature/change as it's finished — do not batch the whole
  website into one commit at the end.
- Keep commit messages concise: under 50 characters, imperative mood
  (e.g. "add navbar", "fix hero spacing").
- Track planned/completed features in [COMMITS.md](COMMITS.md).
